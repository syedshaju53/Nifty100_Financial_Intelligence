============================================================
SPRINT 1 RETROSPECTIVE
============================================================

Project:
Nifty100 Financial Intelligence

Sprint:
Sprint 1 – Data Foundation

Duration:
Day 1 to Day 7

Sprint Goal:

To build a reliable ETL pipeline capable of extracting, validating, transforming, and loading financial datasets into a normalized SQLite database while maintaining high data quality and integrity.

------------------------------------------------------------
What Went Well
------------------------------------------------------------

• Successfully configured the Python development environment.
• Developed reusable ETL modules for data loading and validation.
• Implemented a normalized SQLite database schema.
• Loaded all datasets successfully into the database.
• Created automated validation scripts.
• Generated load audit and validation reports.
• Completed all planned Sprint 1 deliverables.

------------------------------------------------------------
Challenges Faced
------------------------------------------------------------

• Excel files contained inconsistent header rows.
• Some datasets had mismatched column names.
• Foreign key constraint errors occurred during initial data loading.
• Duplicate record insertion caused UNIQUE constraint errors.
• Missing values and inconsistent formats required preprocessing.

------------------------------------------------------------
Solutions Implemented
------------------------------------------------------------

• Corrected Excel header configurations.
• Standardized column names using the data normaliser.
• Filtered invalid foreign key values before insertion.
• Recreated the database schema when necessary.
• Performed comprehensive validation before database loading.

------------------------------------------------------------
Lessons Learned
------------------------------------------------------------

• Importance of validating raw data before loading.
• Understanding relational database design using SQLite.
• Working with Primary Keys and Foreign Keys.
• Building modular and reusable ETL components.
• Effective debugging of data loading and validation issues.
• Maintaining clean project structure and documentation.
